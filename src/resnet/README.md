# ResNet track

ResNet-18 (ImageNet weights) for IE4483 Dogs vs. Cats, plus CIFAR-10 and imbalanced CIFAR-10 studies.

## Layout

```text
src/aidm_project/   data, model, training and evaluation code
scripts/            command-line entry points
configs/            best/worst configs for Dogs vs. Cats and CIFAR-10
tests/              CPU-only unit tests
outputs/            generated runs and submissions (untracked)
data/               datasets (untracked)
```

## Setup

Python 3.11+ and a CUDA GPU (no CPU fallback).

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## Data

- Dogs vs. Cats: `data\dogs_cats\datasets` with `train/{dog,cat}`, `val/{dog,cat}` and `test/`.
- Augmented variant: `data\dogs_cats_augmented` (not regenerated by any script). Pass it via `--data-root`.
- CIFAR-10: `data\cifar10` (downloaded on first use).

## Configs

Both baselines come from the Optuna search (`results\resnet\optuna_search.md`).

| config | val acc | optimizer | lr | batch | fine-tuning |
|---|---|---|---|---|---|
| `*_best.yaml` | 98.86% | NAdam | 8.18e-5 | 64 | full network |
| `*_worst.yaml` | 95.36% | SGD-Nesterov | 1.66e-5 | 16 | classifier only |

Seeds: 2026, 2027, 2028.

## Usage

```powershell
# full grid (27 runs, resumable); or: dvc | cifar | imbalance
.\.venv\Scripts\python.exe scripts\sweep.py all

# tables, figures and error analysis -> results\resnet
.\.venv\Scripts\python.exe scripts\summarize.py
.\.venv\Scripts\python.exe scripts\analyze.py

# single run
.\.venv\Scripts\python.exe scripts\train.py --config configs\dogs_cats_best.yaml --seed 2027
.\.venv\Scripts\python.exe scripts\train.py --config configs\cifar10_best.yaml --imbalance step --method logit_adjust

# predict / evaluate a checkpoint
.\.venv\Scripts\python.exe scripts\predict.py --config configs\dogs_cats_best.yaml --checkpoint <model.pt> --output <submission.csv>
.\.venv\Scripts\python.exe scripts\evaluate.py --config configs\dogs_cats_best.yaml --checkpoint <model.pt> --output <validation.json>
```

Runs are written to `outputs\runs\<dvc|cifar>\<run>\`. Add `--limit 200 --epochs 1` for a smoke test.

## Tests
